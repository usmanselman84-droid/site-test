# Визуал и раскладка ty (2026-09-10)

Проверяли **ty.idivles.ru**: гость (desktop ~1280 + mobile ~390) и USER (кабинет). **py не трогали.**

## Что стоит ровно

- Шапка, меню, футер, адаптив без горизонтального скролла.
- Главная: секции, CTA, карточки сценариев.
- Афиша, коворкинг (форма записи), новости, FAQ, «О нас», privacy.
- USER: стол, друзья, коворкинг «Записаться» (лайм), настройки, Назад/Сохранить на edit.
- Док: подпись **Чаты**; на сообщениях док есть.

## Не баги вёрстки

| Наблюдение | Почему |
|------------|--------|
| `/login` → `/ops` у одного агента | Осталась сессия **TECH**, не гость |
| «Каталог недоступен» на spaces/clubs | Та же служебная сессия; у анонима **карточки пространств есть** |
| Галерея / гранты пустые | Нет контента, страница живая |
| Нет cookie-gate | Уже приняты cookie в браузере агента |
| Edit без дока | Намеренный immersive для формы |
