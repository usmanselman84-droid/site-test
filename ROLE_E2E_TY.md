## Что работает

| Роль | Вход | Кабинет | Служебное | Запреты |
|------|------|---------|-----------|---------|
| Гость | — | редирект на `/login` | `/admin` `/ops` `/scanner` → login `staff=1` | ок |
| USER | ок (капча картинки) | `/dashboard`, `/me`, settings, messages (**Чаты**), friends, applications, coworking, spaces, бронь-календарь | нет | `/admin` → dashboard |
| PARTICIPANT | ок (API) | как USER | нет | staff закрыт |
| MODERATOR | ок | кабинет ок; `/admin` корень открывается | `/ops` → dashboard | `/admin/users`, `/admin/moderation` → `?denied=1` (пустой `permissions`) |
| ADMIN | ок | кабинет + полный `/admin` (users, moderation, bookings/афиша) | `/ops` закрыт (верно) | `/scanner` доступен |
| SCANNER | ок | **весь кабинет редиректит на `/scanner`** | сканер: камера, ручной код, фильтр событий | `/ops` нет |
| TECH | ок | **весь кабинет редиректит на `/ops`** | Ops: модули, площадка, топология, безопасность | `/admin` нет; `/scanner` есть |

Гость: главная, афиша, пространства, клубы, новости, FAQ, логин/регистрация, Яндекс SSO на форме, капча, гамбургер. Защищённые URL не отдают контент без сессии.

## Баги и решения

### P1 — Регистрация не завершается (почта)

**Факт:** `POST /api/register` → **503**, `emailDeliveryFailed: true`, `pendingManual: true`. Текст: заявка принята, почтовый сервис недоступен.  
На ty: `EMAIL_SMTP_BLOCKED` + Resend не доставляет. Новый пользователь в `User` не появляется.

**Решение:** включить исходящую почту на ty (Resend/SMTP) **или** в staging-режиме подтверждать email без письма (авто-verify / очередь PendingUser + кнопка в `/admin/pending-users`). Пока регистрация «как у людей» сломана.

### P1 — `/dashboard/bookings` = 404

**Факт:** в нав/ожидании «мои брони» по этому URL; фактически записи на `/dashboard` («Мои записи»). Браузер: страница не найдена.

**Решение:** добавить `app/dashboard/bookings/page.tsx` (redirect на `/dashboard` или вкладку записей) **или** поправить все ссылки на канон.

### P1 — `/cookies` = 404

Consent/footer ведут в политику cookie, маршрута нет (есть `/privacy`).

**Решение:** страница или `redirect /privacy#cookies`.

### P2 — MODERATOR без прав модерации

`mod@sochi.ru`: `permissions` пустой. ACL: модератору нужен флаг `moderation` для `/admin/moderation`; без JSON он видит только `/admin` и `denied` на разделах.

**Решение:** при выдаче роли MODERATOR писать дефолтный набор из `MODERATOR_PERMISSIONS` (или сид QA). Документировать, что роль без JSON ≠ доступ к очереди.

### P2 — SCANNER / TECH отрезаны от кабинета

Сканер не открывает профиль/чаты/друзей — всё на `/scanner`. Техслужба — всё на `/ops`. Если сотруднику нужна личная запись в коворкинг/чат — сейчас нельзя без второй учётки USER.

**Решение:** явный «личный кабинет» в шапке сканера/ops (`/dashboard/me` без принудительного редиректа) **или** оставить как политику и подписать в UI («служебный режим»).

### P2 — Галерея закрыта для гостя

`/gallery`: «Войдите, чтобы посмотреть». Public status говорит `galleryPublicEnabled: true`.

**Решение:** публичная витрина без логина, если флаг включён; иначе выключить пункт меню для гостя.

### P2 — Логин: rate limit по IP

С одного адреса пачка входов → **429** / лок ~15 мин. За NAT школы/Wi‑Fi пострадают все.

**Решение:** лимит по логину сильнее, чем по IP; whitelist staging; не считать captcha-fail как bruteforce на весь IP.

### P3 — Cookie-gate нестабилен для гостя

Один агент сразу видел сайт без шторки; другой — шит на `/coworking`. Зависит от cookie браузера / SSR.

**Решение:** единый gate до гидрации; не блокировать внутренние страницы иначе, чем главную.

### P3 — Нет `/api/me` (404)

Клиентам удобнее единый endpoint сессии+профиля; сейчас только NextAuth `/api/auth/session`.

**Решение:** не обязательно; либо алиас, либо убрать ссылки если есть.

### P3 — UX регистрации

Только РФ-почта, пароль ≥10 + буква+цифра. Это правило, не баг; на форме уже есть подсказки. Не ослаблять без ТЗ.

### Не баги

- USER не ходит в `/admin` / `/ops`.
- ADMIN не ходит в `/ops`.
- Капча «выберите картинки» решается людьми.
- Bottom nav: **Чаты**, профиль → `/dashboard/me`.
- Staff login `?staff=1` для /admin /ops /scanner.
