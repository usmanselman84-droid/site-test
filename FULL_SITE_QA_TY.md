# Полный аудит ty.idivles.ru — работоспособность, интерфейс, скорость (2026-09-12)

Контур: **только ty** (`ty.idivles.ru`, `/opt/sochi-portal-staging`). py не трогали.

## Как проверяли

- 118 страниц и 161 API-маршрут собраны из исходников; прогон кодов ответа и таймингов
- Роли: гость, `user@sochi.ru` (USER), `qa-admin@sochi.ru` (ADMIN) — вход через штатную капчу
- Headless Chromium, мобильный вьюпорт 390×844: ошибки консоли, FCP/load, вёрстка
  (горизонтальный скролл, пустые блоки >120px, большие вертикальные разрывы, мелкие тап-цели)
- Валидатор вложенности HTML на SSR-выдаче (частая причина ошибок гидратации)
- Скрипты аудита: `qa_ty_audit.py`, `qa_ty_api.py`, `qa_ty_browser.py`, `qa_ty_nesting.py`,
  `qa_ty_hydration.py`, `qa_ty_empty.py`, `qa_ty_flows.py`

## Найденные дефекты и что сделано

| # | Дефект | Причина | Исправление |
|---|---|---|---|
| 1 | React #418 (сбой гидратации) на 14 страницах | `header-boot.js` менял DOM и реагировал MutationObserver-ами **во время** гидратации | Все мутаторы и наблюдатели ждут готовности дерева (`ypAfterHydration` / `ypGuardObserver`), `header-boot.js?v=26` |
| 2 | 401 `/api/user/profile` на каждой странице у гостя | boot запрашивал профиль без сессии | Запрос только при наличии сессии |
| 3 | React #418 на `/clubs` | `<a>` внутри `<a>`: ссылка «Маршрут» внутри карточки-ссылки | Убрана вложенная ссылка из карточки клуба |
| 4 | React #418 на `/contacts` | `SocialIconLink` внутри строки-ссылки соцсети | Добавлен `SocialIconBadge` (span) вместо вложенной ссылки |
| 5 | React #418 на `/coworking` | `CoworkingGuestGate` читал `localStorage` в рендере → первый клиентский кадр ≠ SSR | Чтение после `mount` |
| 6 | Мобильная панель админки 292px почти пустой белизны | у сетки `.admin-layout-wrapper` были области `top/main` без явных строк + `min-height:100dvh` | `grid-template-rows: auto minmax(0, 1fr)` |
| 7 | Пустая полоса ~75px под шапкой во всём кабинете | `padding-top: var(--nav-h)` со времён фиксированной шапки; Navbar теперь sticky и уже занимает место | `padding-top: 0` в кабинете |
| 8 | В чатах на телефоне ~360px занимала панель «Выберите диалог» | десктопная панель треда рендерилась под списком | Скрыта на мобилке, пока тред не открыт |
| 9 | Имя в профиле рвалось посреди слова | `word-break: break-word` при узкой колонке | `word-break: normal` + перенос по словам |
| 10 | В `/admin/users` показывался служебный `nophone:email` | заглушка телефона из регистрации утекала в интерфейс | Показывается «Нет телефона» |

## Замечено, но не менялось

- Кабинет и админка местами «пустые» из-за отсутствия данных на staging: нет заявок,
  броней, участий, портфолио, игр — экраны честно показывают пустые состояния
- Карточка пользователя в `/admin/users` очень высокая на телефоне (метка над значением) —
  требует отдельного редизайна списка
- Ряды фильтров-чипов в каталогах и админке обрезаются справа (горизонтальные рельсы);
  страница по горизонтали не скроллится
- `/login` и `/register` без шапки — так задумано
- `/api/admin/modules` отвечает 404 — проверить, используется ли ещё
- py — только после «одобряю»
