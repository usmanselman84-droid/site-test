# Мобильный UX: баги и оформление (`ty.idivles.ru`)

Дата: 2026-09-09. Viewport **375×812** (Chrome headless, iPhone UA) + ручной прогон computer-use **375×844 / 390×844**.

Плагины/MCP: **PostHog** (heatmaps / session replay) — `needsAuth`, данные недоступны. **Mixpanel** — ошибка discovery. **Figma** не подключался (нет макета в задаче). Использованы: **computerUse**, **Chrome CDP + puppeteer-core**, чеклист HIG 44×44.

---

## Блокеров нет

На всех проверенных URL `scrollWidth === clientWidth` (**375**): горизонтального скролла нет. Битых `<img>` (naturalWidth=0) нет. Меню открывается (`aria-label="Открыть меню"`), `body overflow: hidden`.

Страницы: `/`, `/login`, `/news`, `/events`, `/spaces`, `/coworking`, `/clubs`.

---

## Находки (оформление / a11y тач)

| Сев. | Где | Проблема |
|---|---|---|
| Major | Шапка, все страницы | Кнопки **«Открыть меню»** и логотип-пасхалка игр: **36×36 px** (&lt; 44). Легко промахнуться большим пальцем. |
| Major | Шапка | **«Вход»**: высота **36 px**, ширина ~58. |
| Major | `/login` | Honeypot `website` в вёрстке **32×43** (должен быть скрыт с экрана, иначе риск тапа). **«Обновить проверку»** капчи **34×44**. |
| Minor | Cookie-бар | «Принять» / «Настроить» высота **32**. Ссылки «Политика», «152-ФЗ», «Настройки cookie» высота **17**. |
| Minor | Футер | Юридические ссылки **~17 px** по высоте. |
| Minor | `/events` | Пагинация **1 / 2 / 3** — **36×36**. Чипы «Bugiven», «Нити» узкие (~40–47 px). |
| Minor | `/clubs` | Ссылка **«Маршрут»** ~**98×20**. |
| Minor | Мобильное меню | Пункты **Самоуправление, Добро, Гранты** (и часть разделов) **повторяются** в списке ссылок (чипы + полный список). «Вход»/«Регистрация» тоже дублируются. |
| Minor | Меню | Чипы «Игры», «О нас», «Клубы» высота **30 px**. |

Ложные срабатывания 44px: поля «Электронная почта»/«Пароль» ширина 317 при высоте 44 — ок. Повторы «Подробнее» на главной — это карточки, не баг меню.

---

## Что в порядке (computer-use + CDP)

- Hero, карточки залов/клубов/новостей, карусели, sticky header не перекрывает контент критично.
- Login: капча-плитки, Яндекс, поля с label.
- Overlay меню закрывается, фон не скроллится.
- 390px визуально чуть свободнее, без новых поломок.

---

## Рекомендации

1. Шапка: `min-width/min-height: 44px` на меню, вход, лого-игры (padding, не только иконка 24px).
2. Убрать дубли в drawer: один список разделов **или** чипы, не оба с теми же URL.
3. Honeypot `website` — `sr-only` / `position:absolute; left:-9999px`, не в таб-потоке.
4. Cookie и футер: увеличить hit-area (`padding` / `::after`).
5. Когда будет PostHog: heatmap mobile `viewport_width_max=480` и rageclick на шапку.

Исходный код портала на VPS (`/opt/sochi-portal-staging`); в этом репозитории только отчёт.
